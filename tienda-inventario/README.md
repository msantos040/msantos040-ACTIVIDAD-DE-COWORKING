# TiendaInventario

Proyecto educativo para aprender sobre agentes de IA y Formularios Reactivos en Angular.

## Objetivo
Este repositorio es un proyecto pequeño pensado para que practiquemos los
Conceptos de Formularios Reactivos en Angular "ReactiveFormsModule", "FormGroup", "FormControl", "formControlName", "(ngSubmit)".
Integración y experimentos básicos con agentes de IA o lógica de servicios que procesen formularios.
La app incluye un formulario de ejemplo para crear/editar productos y una lista de productos para ver los cambios.

## Tecnologías

 Angular
 TypeScript
 PNPM
